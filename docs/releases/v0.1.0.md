# GraphWeft v0.1.0

GraphWeft’s first research preview computes ordinary and graph-bicausal optimal transport on up to four binary nodes. It returns both couplings, breaks down cost by node, and shows where a plan violates the conditional distributions required by the graph.

- In the first-order Bikeshare comparison, both optima cost **1.514581**. The saved ordinary plan fails the graph audit while the graph-bicausal plan passes. The full-history fit has a gap of **0.045356**.
- In the household appliance-energy comparison, enforcing the graph constraints raises the cost from **0.292132** to **0.305321**. The entire difference comes from the 18:00 mismatch term.
- In a controlled four-node experiment, adding both edges into an intermediate node lowers the optimum once dependency strength exceeds 0.5. The study includes closed-form checks and a sample-size sweep.

The release includes an installable Python wheel, a source archive with reports and reproduction scripts, and SHA-256 checksums. The studies include independent LP/MILP checks, and the Bikeshare study also includes a comparison with AOTNumerics. [Technical note](https://github.com/stavrespasov/Graphweft/blob/main/docs/technical-note.md) · [Performance benchmarks](https://github.com/stavrespasov/Graphweft/tree/main/benchmarks)

## Reproduce the Bikeshare example

Extract `graphweft_prototype-0.1.0.tar.gz`, open its top-level directory, and run these commands with Python 3.10 or newer in a virtual environment.

```sh
python -m pip install .
python -m graphweft verify-run studies/bike_sharing/chain-search.json
python -m graphweft serve --run studies/bike_sharing/chain-search.json
```

Open the local URL printed by the workbench. The walkthrough follows the evidence from equal total costs to the conditional audit at 18:00. [Bikeshare walkthrough](https://github.com/stavrespasov/Graphweft/blob/main/studies/bike_sharing/REVIEW.md)

The models use supplied information graphs and compatible probability laws. The real-data results are in-sample comparisons of binarized observations. Code is MIT-licensed, and each data study documents its original UCI source and CC BY 4.0 attribution.
